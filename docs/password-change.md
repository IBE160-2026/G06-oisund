# Endre eget passord

Åpne **Brukerinnstillinger** ved **Logg ut** i privat arbeidsrom, og fyll ut gjeldende passord, nytt passord og gjentakelse. Nytt passord skal ha 12–256 tegn; mellomrom beholdes. Passordbehandler og innliming kan brukes.

Lagre eller forkast ulagrede endringer først. Hvis en lagring, sletting eller bekreftelse har ukjent resultat, bruk arbeidsrommets kontroll av forsøket før du åpner innstillingene. Avbryt i passordskjermen endrer ingenting og går tilbake til samme arbeidsrom.

Når endringen er bekreftet, er alle kontoens appøkter logget ut. Logg inn igjen med det nye passordet på hver enhet. Konto, lagret arbeid og de opprinnelige slettefristene beholdes. Endringen påvirker ikke server-/SSH-tilgang eller eventuell ytre tilgangskontroll.

Hvis svaret blir borte, er resultatet ukjent: endringen kan være lagret. Passordfeltene fjernes, og forespørselen sendes aldri automatisk på nytt. Fullfør utlogging med knappen som vises, og prøv deretter det nye passordet. Hvis det ikke virker, kan det gamle fortsatt gjelde.

En frakoblet enhet kan ikke varsles straks. Ved neste tilgangskontroll avvises gamle økter og privat innhold skjules/fjernes. Ulagrede opplysninger som bare finnes i nettleseren kan gå tapt ved økttap. Ingen passord eller private utkast lagres i nettleserens permanente lagring.

Glemt gjeldende apppassord? Bruk [operatørkode og gjenoppretting](password-recovery.md) fra innloggingssiden etter uttrykkelig utlogging.
