# v1.0.1 – driftsrettelser og O3–O6-oppfølging

Vedlikeholdsleveransen siden v1.0.0 oppdaterer gateway-, Python- og PostgreSQL/gosu-imagegrunnlaget, utvider kontrollert backup, gjenoppretting og tilbakeføring, og flytter gateens JWKS-oppslag til en prosess som kan termineres hvis OS-resolveren henger. Releasegrunnlaget inkluderer driftsevidens, historiske reproduksjonsverktøy og sesjonslogger. Passordarbeidet har egen leveranse i v1.1.0.

| Punkt | Sluttstatus |
|---|---|
| O3 | Fullført innen dokumentert omfang. Autentisert produksjonsprøve med økt-, Origin- og CSRF-kontroller, samt fysisk klientnettbrudd og kvitteringsoppslag. |
| O4 | Administrativt lukket. Lokal binding, origin-avslag, Access over IPv4, vertens brannmur og UDP-prosesseiere ble kontrollert. Ruteradministrator rapporterte ingen videresending, UPnP-mapping eller DMZ. Uavhengig WAN-prøve, WAN-adressetype og ruterens IPv6-policy står uten verifikasjon. |
| O5 | Fullført, deployet på `7921eb54e4816aaab9368c3efd851bcf692f3823` og personlig testet. 37 kvalifikasjons- og 20 driftsprøver, backup og isolert restore før/etter, 25 uendrede tabellfingeravtrykk og fem beståtte personlige steg er dokumentert. |
| O6 | Vedlikehold, etterkontroller og triage fullført. Navngitte kernel-, bibliotek- og journalrester følges videre med eksisterende barrierer, ansvar og vilkår for ny vurdering. Midlertidig risikoaksept gjelder sitt dokumenterte omfang. Firmware er separat utsatt. |

[O3-produksjonsprøver](o3-practical-20261102.md), [O4-bevisgrenser](o4-readonly-20261103.md), [O5-deploy](o5-deploy-20261102.md), [O6-overlevering](o6-handover-20261103.md).

På Ubuntu ble systemd 259.9, cloudflared 2026.10.7 og libc6 2.43-2ubuntu2.4 dokumentert aktive etter vedlikehold. Kjørende kernel er 7.0.0-42.42-generic. Journald har den dokumenterte konfigurasjonsbarrieren. Automatisk nattbackup og isolert gjenoppretting ble verifisert. Ved lesende releaseavstemming 4. november var API og database friske på den tidligere deployede commiten `7921eb54e4816aaab9368c3efd851bcf692f3823`. Releasecommiten har identisk app-, container- og deploygrunnlag, med senere driftsverktøy, dokumentasjon, evidens, prosjektinstruksjoner og logger i repoet. [Utført vertsvedlikehold](o6-execution-20261101.md), [backup og etterkontroll](o6-readonly-20261102.md).

## Samling og arkiv

Den felles branchens publiserbare metoder og utvalgte normaliserte data er integrert. Opprinnelig kontekst, fulle data og øvrig evidens kan gjenopprettes fra det verifiserte Git-arkivet. De to lokale committene om avgrenset sesjonslogging er integrert med originalhistorikken. [Historisk grunnlag og gjenoppretting](operations-o3-o6-20261031.md).

`o6-archives-20261102` inneholder også `o6-raw-evidence-20261104.zip` med 144 filer og en separat SHA-256-kvittering. Alle 144 medlemmer ble lest tilbake og verifisert. Git-bundlens hash, seks referanser og gjenopprettede objekter ble kontrollert. Lokal råevidens holdes utenfor publiserte filer.
