Run the current backend selectors through `node scripts/submission.mjs test-backend`, the dedicated current browser selectors through `node scripts/submission.mjs test-browser`, and configuration refusal controls through `node --test scripts/test-submission.mjs`. Do not run historical browser defaults against ordinary databases. Opposite-mode backend skips are expected and are reported by suite; they do not count as passed scenarios.

Field benefit, driver safety outcomes, GPS, live-source completeness, audio, Auto theme, offline mode and a complete accessibility audit have no acceptance evidence in this delivery. Their absence cannot be replaced by simulation, static designs or automated desktop viewport tests.
