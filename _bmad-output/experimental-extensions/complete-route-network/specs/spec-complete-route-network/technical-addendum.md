## Review, persistence and lifecycle

Draft activity → explicit Lookup → inspect source/date/health and unique/alternatives/no-match/insufficient-evidence result → inspect full/selected occurrence range and headsign → keep manual values, select fields explicitly, correct or cancel → save route review → existing overall plan review/confirm. Source unavailable/stale is visible alongside outcome, not empty success. All candidate selection remains a proposal until explicit saved user action. Selecting a source never starts/completes work or provides a location.

Logical resources: normalized bounded public query evidence; owner-scoped draft route-review overlay; selected immutable workday reference. No full catalogue schema, raw shift archive or automatic-notice resource. Q7 proposes current+one previous public query result per bounded scope, with actual item/byte/idle-retention bounds settled before persistence. Private selected facts, manual direction/destination/stops, field-level keep/replace decisions and evidence references expire with the parent only. Public caches contain no private activity ID/notes. Unreferenced staging is bounded/discarded, never an indefinite archive.

Route-review saves use expected draft and overlay/source revisions plus stable operation identity/lookup. Uncertain reply retains original proposal/body; conflict shows comparison, no forced overwrite; known validation/capacity rejection is separate from uncertain commit; denial hides private data. Re-read current authority before applying old receipts. Removing/changing an activity/service date/time/mapping invalidates the affected review; preserve explainable prior choices while unresolved. Confirmation and review save serialize on the same parent so a concurrent edit cannot freeze the wrong association set. Existing V1 acknowledgements still apply; no match alone is not a new blocker.

Confirmed/active/terminal plans expose only the frozen planned reference; no re-enrichment mutation. Draft refresh creates an inspectable difference; it never overwrites manual values or silently transfers a confirmation to changed IDs/calendars/patterns. Carry selected source facts under fixed existing parent expiry even if public evidence rotates. Deletion/expiry purges private overlays/receipts/references; polling/login/retry cannot extend or resurrect them. Private/demo separation and no persistent private browser cache apply from S1.
