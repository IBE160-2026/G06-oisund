## Automatic-notices dependency review

Read remote planning branch `origin/codex/plan-automatic-notices`: `scope.md`, `bmad-workflow.md`, and `specs/spec-automatic-notices/technical-addendum.md` beneath `_bmad-output/experimental-extensions/automatic-notices/`. That plan proposes server-side Entur TRO retrieval/coordinator, bounded source state and owner-scoped review overlays through existing private authorization. It needs source/page semantics, line/stop mapping and lifecycle qualifications. Password management needs none of those data sources or mappings; automatic notices does not require password recovery to collect public source data.

Shared integration surfaces are session authorization, React private shell, PostgreSQL migrations/cleanup, owner-scoped overlays and Ubuntu packaging. The notice plan references an older product baseline; a later joint release must rebase/reassess it against then-current main. No code or planning documents from that branch were imported or modified.
