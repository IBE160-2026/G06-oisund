## Proposed measurement, pending Q-6

Proposal: at least 30 independently labelled plan/message cases covering two representative workdays and every case family; five paired Entur/Svipper reference checks where corresponding material is available. Missing counterpart cases are recorded, never fabricated. This small sample cannot establish regional completeness or statistical reliability.

Proposal: every truthfulness/preservation invariant passes; no uncertain automatic result is labelled confirmed and no failed/partial collection is labelled complete/zero. Separately target at least 95% recall and 90% precision for line/time nominations within the labelled qualified subset. Recall = nominated expected candidates / all expected candidates; precision = correct nominations / all nominations. Keep unknown/unadjudicable cases in a separate reported count with reasons, not silently removed to improve scores. Report raw counts/denominators; zero denominator is not evaluable, never 100%.

Proposal: owner/driver distinguishes possible relevance, user association, source close, not-seen and stale/partial data in all selected walkthrough cases. Measure manual source-check time, review workload and false/missed candidates against the same workday reference process. A required saving target needs a measured baseline and owner decision; none exists in research.
