# Instruksjoner for Codex

Les og følg prosjektets [CLAUDE.md](CLAUDE.md). Les også
[sesjonslogg-oppskriften](.claude/skills/sesjonslogg/SKILL.md), og bruk den når
vilkårene der gjelder. Henvisningene gjelder de faktiske filene: åpne og les dem;
ikke baser deg på automatisk behandling av `@`-importer.

Følg lærerens oppskrift for sesjonslogging før sluttoppsummeringen, vedlikehold
åpne punkter i brukerens `issues.md`, og commit bare loggfilene lokalt slik
oppskriften angir. Prosjektets egne regler og brukerens eksplisitte instruksjoner
er førende. Ikke push uten uttrykkelig beskjed fra brukeren.
